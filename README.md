# Landing Page - Proyecto Final del Módulo 2 del Bootcamp Java Trainee

## Descripción del Proyecto

Este proyecto corresponde al desarrollo de una Landing Page diseñada como entrega final del **Módulo 2 del Bootcamp Java Trainee** de **Talento Digital Chile**. La página refleja la experiencia adquirida en maquetado web, diseño responsivo y funcionalidades interactivas, integrando tecnologías modernas para garantizar una interfaz atractiva y funcional.

## Tecnologías Utilizadas

1. **HTML Semántico**:
   - Se utilizó para estructurar y organizar el contenido de manera clara, mejorando la accesibilidad y el SEO.
   - Implementación de etiquetas semánticas como `<header>`, `<section>`, `<article>` y `<footer>` para un diseño coherente.

2. **Bootstrap CSS**:
   - Framework utilizado para estilizar y garantizar un diseño completamente responsivo.
   - Se emplearon componentes de Bootstrap como **tarjetas**, **botones**, **formularios** y **grillas**, asegurando una experiencia visual moderna y profesional.

3. **JavaScript**:
   - Implementación de funcionalidades dinámicas, como:
     - **Envío de formularios de contacto**.
     - Generación y presentación dinámica de las tarjetas que muestran los proyectos destacados.
     - Validaciones y efectos interactivos para mejorar la experiencia del usuario.

## Características de la Landing Page

- **Sección "Sobre Mí"**:
  - Presentación personal destacando habilidades, experiencia y tecnologías de especialización.
  
- **Sección "Habilidades"**:
  - Íconos interactivos que muestran las principales tecnologías dominadas: HTML5, CSS3, JavaScript, Bootstrap y Python.

- **Sección "Proyectos"**:
  - Visualización de tres proyectos destacados con tarjetas interactivas que incluyen:
    - Imagen representativa del proyecto.
    - Descripción breve y funcionalidad clave.
    - Botón de acción para obtener más información.

- **Formulario de Contacto**:
  - Sección funcional para que los usuarios puedan enviar mensajes de manera sencilla.
  - Incluye validación básica para los campos requeridos.

- **Diseño Responsivo**:
  - Compatible con dispositivos de diferentes tamaños, adaptándose perfectamente tanto a móviles como a pantallas más grandes.
